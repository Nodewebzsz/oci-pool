1 正常态 A3 / B1 / B2 / B3 / B4 / C1 / C2 环境列显示「控制台 / API」徽章；事件列为短名；响应列为「语义徽章 + 原始码」；201 / 204 判为成功；- 判为「未知」不染红；底部只有「已加载 N 条 · 还有更多」+「加载更多」，无页码条 / 跳页框 / 共 N 条；序号列 36px；源 IP 列 120px + 省略号 + hover 看全。
2 首屏加载中 — 骨架屏占位，不显示任何旧数据；「加载更多」禁用；筛选栏查询按钮禁用。
3 加载更多中 B4 已有行不消失、不重排；仅尾部追加；按钮变「加载中…」且不可重复点击。
4 空态 A2 真实空结果显示空态并给出放宽范围的操作；不得出现任何事件行。
5 错误态 A1 / A4 超过 90 天、格式非法、OCI 查询失败三种情况都必须报错；错误文案要说明具体原因（图示为「日期范围不能超过 90 天」）；提供重试。
6 已达加载上限 B4 达到 2000 条后停止追加，文案提示「已达上限，请缩小时间范围」，按钮隐藏。
7 演示数据提示 A2 仅当保留 mock 兜底时适用：响应需带 mock: true，前端置顶横幅明确标记为演示数据。
