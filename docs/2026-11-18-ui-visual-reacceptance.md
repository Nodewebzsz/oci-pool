## 确认的问题与修复顺序

### 1. P1：共用页头不适配可用宽度

- 默认窗口：CF 标题被压成 `CF / 管 / 理` 三行，副标题只剩 `Clo…`，页头异常增高。
- 最小窗口：租户、实例、开机页均出现标题不可见、工具按钮越出右边界、页头侵入左侧栏；实例页巨大空白页头明显挤压列表可视高度。
- 来源：`Common/Components/PageScaffold.swift:92` 对工具栏使用 `.fixedSize(horizontal: true, vertical: false)`，并与标题放在同一 HStack；各页工具栏缺少分行及收缩方案。
- 建议：先修共用页头，保障标题和副标题的宽度；长工具栏按可用宽度移至第二行或分组换行。表格的横向滚动不能被当作页头横向溢出的解决方式。再检查 CF、租户、实例、开机四页，覆盖 Claude / 经典与深浅色。

### 2. P1：已开机任务仍展示可用的“启动”按钮

- 真实任务卡明确显示“已开机”，下方却仍有强调色“启动”按钮；任务列表菜单对已完成任务会禁用启动，两个入口规则不一致。
- 来源：`Features/Boot/BootDetailView.swift:352` 仅以 `status == 1` 区分停止/启动，其余状态均显示启动，未排除已完成状态 2；`toggleDetailStatus` 也只有确认弹窗，没有已完成状态检查。
- 建议：统一详情和列表的状态规则，已完成任务禁用启动，并提供明确原因。后续用隔离测试数据验证，不能通过点击真实任务来测试。
- 本轮未点击该按钮，未触发确认弹窗或写入。

### 3. P2：区域页标题没有适配 Claude 标题方案

- 监控、租户、实例、开机页使用较大的衬线页标题，区域页使用较小的无衬线字，页面层级明显不一致。
- 来源：`Features/Regions/RegionsView.swift:65` 自建标题固定使用 `.system(size: 17, weight: .semibold)`，未采用共享 `AppTypography.pageTitle`。
- 建议：共享标题令牌和页头规范，保留经典方案原有字体选择。

### 4. P2：回源工具底栏直接展示原始时间字符串

- 更新时间包含 `T`、毫秒和 `Z`，在底栏中被拆成多行，末尾毫秒另起一行，影响底栏对齐和扫描阅读。
- 来源：`Features/Cloudflare/CloudflareSheets.swift:282` 直接插入 `fetchedAt`。
- 建议：解析后展示本地时区、秒级精度的短时间；完整时间可作为辅助提示，底栏信息和操作需自适应排列。
