## 未通过项

### P1：CF 管理页头操作区挤压标题

用户指出 UI 问题后，重新检查正式版完整截图：页头标题“CF 管理”被压缩为“CF / 管 / 理”三行，副标题仅剩“Clo…”，导致页头高度异常增大。域名选择及六个操作按钮占据同一行，标题区缺少最小宽度和响应式布局保护。该问题此前未通过完整截图检查，属于本轮漏检，不能作为通过项。

应将页头标题与操作区分行或按可用宽度自适应排列，保障标题完整显示，保留 Claude / 经典的既有视觉风格。修复后需检查两种设计及深浅色在常用和最小窗口宽度下的完整页面截图。

### P1：主账号画像漏掉父级 ID 为 0 的历史主账号

监控页显示主账号 0 个，而租户列表有 9 条主账号记录。安装前备份的只读汇总结果：租户记录共 12 条，`PAREN_ID IS NULL` 为 0 条，`PAREN_ID=0` 为 9 条，`IS_HOME_REGION=TRUE` 为 9 条。

`TenantServiceImpl.getTenantPortrait()` 与 `computeTenantPortrait()` 仅以 `getParenId() == null` 判断主账号，漏掉父级 ID 为 0 的既有记录。修复应兼容现有主账号表示方式，增加父级 ID 为 0 的回归用例，不能通过修改真实租户数据规避问题。

### P2：已过期 Token 仍展示“已生成 · 有效”

同一页面的剩余天数显示“已过期”，状态却显示“已生成 · 有效”。需让展示状态结合过期时间判断，并核对文档面板的 Token 可用提示。此次未生成、撤销或修改 Token，也未调用开放接口验证该 Token。
